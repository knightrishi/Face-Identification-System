Face Identification System

A criminal identification and facial recognition system designed to assist investigation departments in identifying suspects using facial image processing and database-driven matching techniques.

The system allows operators to store criminal records, split facial images into segments such as eyes, nose, lips, and hair, and reconstruct faces based on eyewitness input. The generated face is then matched against stored criminal databases to identify potential suspects with high accuracy.

Core Features
Criminal record management
Face image segmentation and reconstruction
Eyewitness-assisted suspect identification
Facial feature comparison and matching
Secure admin and operator authentication
Database-driven image retrieval
Image splitting and merging modules

Objective

To provide a fast, secure, and automated criminal face identification mechanism that reduces manual investigation effort and improves suspect recognition efficiency.
